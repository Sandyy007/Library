2. Product Description

Library Management System is a complete desktop solution for automating the day-to-day operations of a library. It provides cataloguing of books, member management, issue and return of books with due-date tracking, overdue alerts, category management, reporting, and a customizable administrative dashboard. The software runs entirely on a single Windows machine — the application automatically starts its own backend service on startup and stores all data in a local MySQL database, requiring no internet connection for regular operation.

3. Key Features

3.1 Book Catalogue Management

  • Add, edit, view and delete books with full bibliographic details: ISBN, title, author, publisher, year of publication, rack/shelf number, category, and description.
  • Support for multiple copies per title with independent tracking of total copies and currently available copies.
  • Automatic book status maintenance — available, issued, or all copies issued — updated as books are lent and returned.
  • Attach and store a cover image for each book.
  • Advanced filtering by title, author, category, year, availability and status.
  • Bulk delete of multiple books at once, with a built-in safeguard that blocks deletion of any book that has active (issued/overdue) loans.

3.2 Member Management

  • Create and maintain member records with name, email, phone, address, profile photo, membership start date and expiry date.
  • Multiple member types including student, faculty, staff, guest and custom official designations (e.g. Deputy Director, Assistant Commissioner, State Tax Officer and others).
  • Activate / deactivate members without deleting their records, preserving historical data.
  • View a member's currently borrowed books and full borrowing history.
  • Membership validity/expiry tracking.
  • Bulk delete of members with protection against removing members who hold active loans.
  • Upload and store a profile photo for each member.

3.3 Issue & Return of Books

  • Issue books to members with automatic due-date calculation based on the member category's loan period.
  • Enforcement of per-category borrowing limits (maximum books allowed) and loan durations.
  • Availability checks that prevent issuing when no copies are free.
  • Return processing that automatically updates copy availability and book status.
  • Edit issue records (due date, return date, status) and delete or bulk-delete issue records where permitted.
  • Complete circulation register of all issue and return transactions.

3.4 Borrow Slip Generation

  • Generate a printable borrow slip for any issue transaction as an acknowledgement/receipt.
  • Retrieve borrow slips by slip ID or by issue ID, list all slips, and delete slips.

3.5 Overdue & Due-Soon Tracking

  • Automatic recalculation of overdue status whenever issues, reports or the dashboard are accessed.
  • In-app notifications for overdue books and books due soon.
  • Ability to log reminder actions against an issue, recorded as a notification entry for audit.

3.6 Category Management

  • Manage book categories (create, edit, delete) with descriptions; ships with 40+ predefined categories.
  • Manage member categories with distinct borrowing rules — configurable maximum books and loan period per category.

3.7 Bulk Data Import

  • Import books and members from CSV and Microsoft Excel (XLSX) files.
  • Optimised batch import engine capable of handling large datasets (10,000+ records) efficiently.
  • Minimal required fields (title + author for books) with optional fields such as rack number and ISBN.

3.8 Dashboard & Reports

  • Customizable dashboard with configurable, re-orderable widgets per user.
  • Real-time statistics — total books, members, active issues, overdue counts and other KPIs.
  • Actionable alerts and a recent activity feed (with option to clear/hide activity).
  • Reports for issued books, overdue books, most popular books (by period) and active members.
  • Report result limits suitable for exporting large lists.

3.9 Search

  • Fast, database-indexed search across books (title, author, ISBN, category) and members (name, email).
  • Pagination support throughout to keep performance smooth on very large catalogues.

3.10 Security & Access Control

  • Administrator login with bcrypt-hashed passwords and JWT-based session tokens.
  • Forced password change on first login and a dedicated change-password flow.
  • Rate limiting on login attempts to deter brute-force attacks.
  • HTTP security headers (Helmet), input validation, and CORS protection.

3.11 File & Image Handling

  • Upload and store book cover images and member profile photos (JPG / PNG).
  • Images stored locally on the machine and served to the application.

3.12 System Health & Reliability

  • Built-in health-check endpoints (basic and detailed, including database status) for diagnostics.
  • Automatic database migrations on startup to keep the schema and performance indexes up to date.
  • Response compression and request logging for stable performance.
