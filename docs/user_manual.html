1. About This Manual

This manual explains how to use the UPSTTRI Library Management System — a desktop application for managing books, members, and the daily issue/return operations of the library. It is written for the administrator/librarian, who is the only role that signs in to the system.

Each section walks through a task with numbered steps. Look out for the coloured boxes:

Tip — a helpful shortcut or best practice.
Caution — an action that cannot easily be undone.

2. Getting Started

2.1 System Requirements

ItemRequirement
Operating SystemWindows 10 or 11 (64-bit)
DatabaseMySQL 8.0+ (installed and running)
Disk Space~300 MB for the application plus space for the database and uploads
Display1366×768 or higher recommended

2.2 Installing the Application

1. Run the provided installer (created with Inno Setup) and follow the on-screen prompts.
2. Ensure MySQL is running and the library_management database has been created and loaded from schema_v2.sql (your IT team usually does this once).
3. Launch the application from the Start Menu or desktop shortcut. The bundled backend service starts automatically.

2.3 Logging In

1. On the login screen, enter your username and password.
2. Click Login.
3. On first login you are required to change the default password. Choose a strong new password and confirm it.
RoleDefault UsernameDefault Password
AdminadminLibrary#123
Only admin accounts can sign in. After too many failed attempts (15 within 15 minutes) login is temporarily blocked to protect against brute-force attacks. Wait a few minutes and try again.
Change the default password immediately and store the new one securely. Sessions expire automatically; if you are logged out, simply sign in again.

3. Understanding the Interface

After login the main window appears with two areas:

  • Sidebar (left): primary navigation, quick actions, theme toggle, and logout.
  • Content area (right): shows the screen for the selected menu item.

3.2 Quick Actions & Top Bar

  • Advanced Search — open a multi-field search dialog from the sidebar quick actions.
  • Backup & Restore — open data backup tools from the sidebar quick actions.
  • Notification bell — shows unread alerts with a count badge.
  • Theme toggle — switch between light and dark mode.
  • Logout — sign out securely.

4. The Dashboard

The Dashboard is the home screen and updates in real time.

4.1 What You See

  • KPI cards: total books, issued, available, overdue, and active members.
  • Library Statistics chart: a bar chart of books by category.
  • Book Status Distribution: a pie chart of available vs issued copies.
  • Actionable Alerts: colour-coded sections for overdue, due-today, and low-stock items, each with a View All option.
  • Recent Activity: a live feed that refreshes automatically every few seconds.
Use the alerts panel each morning to quickly spot overdue loans and books due back that day.

5. Managing Books

Open Books from the sidebar to view the catalogue. Each book shows its title, author, category, availability, and cover image.

5.1 Adding a Book

1. Click Add Book.
2. Fill in the details: title and author (required), plus ISBN, category, rack number, publisher, year, and description.
3. Set Total Copies. The available count is tracked automatically as books are issued and returned.
4. Optionally upload a cover image and preview it.
5. Click Save.

5.2 Editing or Deleting a Book

  • Edit: click the edit icon on a book row, change the fields, and save.
  • Delete: click the delete icon and confirm. Use bulk delete to remove several selected books at once.
Deleting a book also removes its issue records. Make sure no copies are currently on loan before deleting.

5.3 Categories

Manage genres/categories from the books area. You can create, rename, and delete categories used when classifying books.

5.4 Importing Books in Bulk

1. Click Import and choose a .csv or .xlsx file.
2. The system maps common column headers automatically (title, author, ISBN, category, etc.).
3. Review and confirm the import.
Search and filter the catalogue by title, author, category, year, or availability to quickly find a book.

5.5 Exporting Books

Export the catalogue to CSV or JSON for backup or external reporting using the export option in the books toolbar.

Open Members to view the member directory. Members are grouped by type, each with its own borrowing limits.

6.2 Adding a Member

1. Click Add Member.
2. Enter name (required), email, phone, address, and member type.
3. Set the membership date and optional expiry date.
4. Optionally upload a profile photo.
5. Click Save.

6.3 Editing, Activating & Deactivating

  • Edit: click the edit icon, update details, and save.
  • Activate / Deactivate: toggle a member's status. Deactivated members cannot borrow new books.
  • Bulk delete and CSV/JSON export are available from the toolbar.

6.4 Viewing Borrowing History

Open a member to see their current loans and full borrowing history, including statistics dialogs that summarise their activity.

7. Issuing & Returning Books

Open Issues & Returns to manage circulation.

7.1 Issuing a Book

1. Click Issue Book.
2. Select the member and the book (only available copies can be issued).
3. The due date is calculated automatically from the member's type.
4. Confirm to issue. The available copy count decreases automatically.
You can print a borrow slip for the member after issuing.

7.2 Returning a Book

1. Find the active issue in the list (filter by member or overdue status if needed).
2. Click Return.
3. If the book is overdue, a fine is calculated and shown.
4. Confirm. The copy becomes available again immediately.

7.3 Overdue & Reminders

  • Overdue and due-soon items appear on the dashboard and in this screen.
  • Use Send Reminder to record a reminder, or Mark Returned to process a return directly.
  • You can edit an issue to extend the due date or change its status.

9. Notifications

The notification bell in the top bar shows an unread count.

  • Click the bell to view notifications: overdue, due-soon, new-book, system, and status messages.
  • Mark notifications as read individually or all at once.
  • Delete notifications you no longer need.
  • Notifications refresh automatically and update instantly after you change data.

10. Search & Recommendations

10.1 Global & Advanced Search

  • Use the Advanced Search quick action to search across books, members, and issues with multiple filters.
  • Results open in a dialog where you can jump directly to a record.

10.2 Recommendations

Open a member to view book recommendations generated from their borrowing history — useful for suggesting titles at the desk.

11. Backup, Restore & Data Export

Open Backup & Restore from the sidebar quick actions.

11.1 Creating a Backup

1. Click Backup to download a single JSON file containing books, members, and issues.
2. Store the file in a safe location (external drive or network share).
Perform regular backups — at minimum weekly, and always before a large import or before deleting records.

11.2 Restoring from Backup

1. Click Restore and select a previously created JSON backup file.
2. Confirm to restore the data.
Restoring replaces existing data with the backup contents. Only restore from a trusted, verified backup file.

11.3 Exporting Data

Books, members, and issues can each be exported to CSV or JSON from their respective screens for use in spreadsheets or other systems.

12. Settings & Themes

  • Theme: use the toggle in the sidebar to switch between light and dark mode. The choice is remembered.
  • Dashboard widgets: widget visibility and layout are saved per user.
  • Password: you are prompted to change the default password on first login; keep it secure.

13. Troubleshooting & FAQ

ProblemSolution
Cannot log inCheck username/password. After 15 failed tries, wait 15 minutes. Confirm the backend and MySQL are running.
App shows no data / connection errorEnsure MySQL is running and the database is loaded. Restart the application so the bundled backend relaunches.
Session expired messageThis is normal after inactivity. Simply log in again.
Cannot issue a bookThe book may have no available copies, or the member is inactive or at their borrowing limit.

14. Keyboard & Quick Tips

  • Check the Dashboard alerts daily for overdue and due-today items.
  • Use Advanced Search to locate records fast instead of scrolling.
  • Run a Backup before bulk imports or bulk deletes.
  • Keep member types accurate — they control borrowing limits and loan periods automatically.
  • Export reports to PDF for printing and Excel for further analysis.
